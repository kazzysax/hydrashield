## Special award: Best Use of HydraDB

- Strong versioned dependency graph model
- Reverse reasoning from advisory to internal application
- Multiple evidence paths retained rather than collapsed into similarity scores
- A problem that vector retrieval cannot answer exactly
- HydraDB is required for the production backend; removing it removes the core reasoning capability
